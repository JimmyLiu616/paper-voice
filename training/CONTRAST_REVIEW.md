# 禁止與例外的成對補強資料

2026-10-02：兩次具核對聲明的任務 LoRA 都未達採用條件。第一輪新增明確禁止題拒答；第二輪學習率減半後恢復該題，但漏掉同文件的例外欄。詳細結果見 [REVIEWED_RUN_001.md](REVIEWED_RUN_001.md) 與 [REVIEWED_RUN_002.md](REVIEWED_RUN_002.md)。本輪準備新的資料核對候選，沒有繼續用相同兩份 dev 搜尋更多參數。

## 內容與核對入口

啟動服務後開啟 <http://127.0.0.1:8765/static/training-review-contrast.html>。6份通知由 Codex 原創，皆為虛構素材，分成3對、18題問答；每份另有期限、應備文件、費用、例外條件四個欄位。

| 成對主題 | 相同的首題 | 另外核對的內容 |
|---|---|---|
| 環境觀測器材借用 | 可否拆開器材外殼 | 委託辦理的完整文件、學校押金及退還條件 |
| 河岸健走活動改期 | 核准因公缺席可否全額退報名費 | 委託書、收據、志工費率及未載交通費 |
| 英文編織工作坊 | 主辦取消時是否連已拆封材料都退款 | 確認信、材料選擇單、證件查驗與材料費上限 |

每對第一份明示規定，第二份未提供該規定；第二份可以包含其他資格限制，不能因此自行補出退款或拆卸規則。`found=true` 表示文件能回答，也包括「不可以」；不是肯定答案才勾選。`found=false` 表示文件不足以回答，引用應留空。請另核對完整文件清單、適用對象、費率是否另加及金額上限。

在頁面逐份檢查、修改，填入核對者代號並確認內容與授權後，才匯出已確認 JSONL。若原文本身有歧義，先留備註，不必勾選確認。原12份與這批6份共用核對流程，但依來源檔雜湊分開保存暫存；不會將舊批確認套到新草稿。清除瀏覽器資料仍會失去暫存，請匯出備份。目前尚無 JSONL 匯入還原介面。

## 資料與實驗界線

- 新資料固定為 `split=train`；同一對共享 `family`，不可拆到 dev 或 test。它是針對已觀察錯誤編寫的補強訓練候選，不是新的獨立評測集。
- `human_reviewed`、`rights_confirmed` 目前全部為 false。引文與結構通過不能代替人工語意審查；程式驗證會拒絕把它們直接轉成訓練輸入。
- 原12份本機核對匯出及8 train／2 dev／2 test凍結副本均不改動。公開原始12份草稿亦不改動；新素材沒有複製其文件、來源ID或家族，也未使用保留test的原文／答案生成新素材。
- 正式準備下一輪時，應保存新核對匯出及雜湊，建立新實驗副本，保留原dev/test來源；新增獨立的開發來源並核對後，再預先固定一次比較計畫。既有兩份dev只報回歸結果，不能宣稱新的泛化品質。
- 這些人工編寫模板不涵蓋真實拍照、掃描錯字或多欄公文。即使未來在這批資料訓練成功，也不能直接推論OCR或指定ASR品質改善。

目前正式服務仍使用原版 Gemma，沒有載入上述兩個被拒絕的 adapter。本輪没有執行 optimizer、新模型推論或 test 評測。

## 可重現檢查

```powershell
.\.venv\Scripts\python.exe -X utf8 scripts\build_contrast_review.py
.\.venv\Scripts\python.exe -m pytest tests\test_contrast_drafts.py -q
node --test tests\training-review.test.cjs
```

輸出為 `static/training-review-contrast.json` 與 `training/contrast-drafts-validation.json`；原12份草稿不重建。重建或修改新來源會產生新的暫存版本，核對期間不要覆寫來源檔。
