# 本機台語翻譯與讀音草稿

部署為**需人工核對的實驗草稿**。模型為 SARC 官方 Gemma 3 12B GGUF Q3_K_L；固定 revision 與完整 SHA256 見 `plan.json`。以現有 Ollama 成功載入 8 GB GPU，避開先前 Transformers 格式的 Windows 記憶體問題。下載成功及推論成功不等於翻譯品質達標。

## 觀察與修正

第一輪六句直接翻譯：文件種類及紙本限制有保留，但「115年」被寫成「一千一百五年」，且出現回覆標題。因此沒有採用直接輸出，完整回覆見 `results.jsonl`。

第二輪改為 JSON 單一譯文欄，將阿拉伯數字先換成標記。六句皆保留標記；日期回復為115年、費用回復為300元。另在生成前固定四句新測試，涵蓋逾期不受理、正本及影本、年齡免繳及已繳者免再繳。四句的主要條件仍在回覆中，數字標記亦完整。完整輸出見 `protected-results.jsonl`、`heldout-results.jsonl`，不把10句當成一般準確率或母語者評分。

正式流程檢查標記次數、順序、新增阿拉伯數字及常見日期／金額／數量單位；缺漏或改錯就拒絕套用。這不能驗證否定或完整語意，也沒有驗證中文數詞的所有改寫。例外與條件仍須人工核對。

符合範圍的0–9999整數可產生漢字數詞草稿，再經 Taibun 轉白話字；初次8句可完整轉寫，2句因「逾／仍」字典未收錄而停止，沒有丟掉字繼續朗讀，見 `pipeline-before-lexicon.json`。後續修復與最終結果見下方。電話、編號、前導零、小數等不猜讀，返回需人工處理的訊息。這是轉寫可用性，不代表詞彙、變調、口音自然。

## 實際網頁

真實圖片辨識後，在「何時以前」帶入原文。網頁顯示保留數字的譯文、漢字数詞讀音及白話字，人工確認仍為 false，見 `browser-deadline.json` 及 `workspace.png`。該讀音另以模型合成為7.184秒的16kHz WAV，格式通過；這是技術驗證，沒有冒充母語者確認。

新端點只接受目前已完成文件的連續原文，最多80字；確認框不自動勾選，不自動播放。若使用者修改文字或換文件，遲到的翻譯不覆寫新內容。前端提供文件重點選單，不截斷較長原文來繞過上限。

## 耗時與限制

GGUF 首次推論（含模型切換／載入）約20–41秒，預載後短句約1.5–4秒；正式流程會釋放 SARC 並在背景恢復 Gemma，因此連續翻譯可能重新載入，不能承諾每句只需數秒。照片加速是另一項改善。兩個大模型不長期一起占用8GB顯卡。

263項 Python、35項 JavaScript 測試通過。新增保護測試涵蓋數字遺漏、重複、順序、單位、新增金額、非法來源、錯誤權重版本、截斷、模型錯誤後恢復與過期前端結果。台語自然度與語音品質待母語使用者評估；客語仍只提供核對後漢字朗讀，未自動翻譯。

[模型作者及授權](https://huggingface.co/Speech-AI-Research-Center/SARC-Taigi-LLM-12b-GGUF)：SARC模型遵循Gemma條款；MMS語音權重CC BY-NC 4.0；Taibun程式MIT，詞庫依其聲明為CC BY-SA 4.0。大型權重僅本機下載，未加入GitHub程式庫。


## 字典缺詞的後續修復

首次轉寫只有8/10句成功，新增句中的「逾／仍」未收錄，初始結果保留於 `pipeline-before-lexicon.json`。讀音草稿現在只針對明確句型將「逾期不受理」改為「過期不受理」、「仍須繳費」改為「猶原愛繳費」；上方模型譯文不改，畫面提示替換，其他未知字仍拒絕處理。這是根據本組失敗案例作的開發修復，不能當作獨立測試得分。

詞義參照教育部辭典：[過期](https://sutian.moe.edu.tw/zh-hant/su/28743/)、[猶原](https://sutian.moe.edu.tw/zh-hant/tshiau/?iahbe=1&lui=tai_su&pitsoo=100&tsha=%E7%8C%B6%E5%8E%9F)、[愛（需要／必須）](https://sutian.moe.edu.tw/zh-hant/su/9427/)。整句口語自然度仍待人工核對。

最終10/10句可完整轉寫，見 `pipeline-checks.json`。另外四句（文件、逾期、年齡費用、已繳費例外）實際合成3.584–10.128秒的WAV，見 `extra-audio-checks.json`；沒有以成功合成當作發音品質認定。
