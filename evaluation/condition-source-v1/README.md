# 例外欄的原文定位修正

2026-10-02。既有 public-v11 警察證明表格的模型輸出其實包含「不予核發」的限制及兩項列舉，但 evidence 錯配到應備文件段落。舊驗證器因此捨棄模型值，改用另一段辦理時間例外。這個失敗與資料缺漏不同：限制文字已在辨識逐字稿，也在模型 value 中。

候選僅修正 conditions 欄：當原 evidence 不通過時，先判定帶有明確限制語詞的 value 是否可唯一對應到原文完整行範圍。比較容許既有 NFKC／空白正規化，輸出仍取回原始字元與換行；前綴只能是列舉符號，尾部只能剩標點，前一行若可能是未完條件也拒絕復原。改字、改數字、重複來源、截掉否定／尾句、超過1200字均不復原。無法復原時保留舊有處理，不套用到問答。

恢復另一段限制時，原先辦理時間的例外會以完整來源段落留在摘要提醒，避免只剩半句或遺失已顯示的條件。沒有修改模型權重、提示詞、圖像前處理或问答驗證。
