# 阿美語翻譯草稿自動朗讀驗證

日期：2026-10-02。範圍：中文短句 → NLLB 阿美語譯文 → MMS 合成 → 瀏覽器自動播放。使用者要求移除人工核對步驟，API 與 UI 皆沒有確認閘門。

- `plan.json`：推論前保存的 5 個測試短句、固定模型版本、預設秀姑巒語別。
- `downloads.json`：固定 revision 下載清單與各檔 SHA256；權重未上傳 GitHub。
- `probe-before-apostrophe.json`：初次實測保留的失敗紀錄，3/5 因 NLLB 使用 U+02BC 撇號、MMS 僅接受 ASCII 撇號而無法合成。
- `probe.json`：修正等價撇號轉換後，5/5 完成翻譯及 16 kHz PCM WAV 合成。保留所有生成譯文，沒有人工挑選替換譯文。語音長度 1.264–15.216 秒。這是技術流程成功率，**不是翻譯正確率**。
- 本機模型已載入的批次觀察：每句翻譯約 2.9–10.9 秒，含合成約 3.3–13.4 秒；不含 Python 冷啟動及每次模型載入，不能當作 API 完整延遲。
- 瀏覽器實際按範例與「翻譯並朗讀」，得到 `awaay ko payso, awaay ko ʼaca.`，播放器觀測 `paused=false`、`currentTime=1.228641`、`duration=3.008`、`readyState=4`，其後自然播放結束。没有勾選確認。UI 截圖與音檔只存本機 `.runtime/amis-demo/`。

## 品質邊界

沒有母語者評分，沒有驗證法律／公文資訊的語意忠實度。長日期句的年份、數字及申請條件讀法未驗證，不可用「5/5」宣稱內容皆正確。五種譯文語別只有秀姑巒跑過以上完整實測；其他語別使用模型提供的目標 token，但未做品質比較。所有語別共用同一 MMS 聲音，不宣稱五種腔調 TTS。

日期、金額、否定、例外可能被模型誤譯；畫面並列原文與 AI 草稿，沒有用警語新增人工確認步驟。模型不支援的文字不會靜默略過，語音失敗保留譯文並回報原因。停止、修改輸入與換文件會丟棄遲到回應，避免舊語音自行播放。

## 重現

先依 README 下載模型，再啟動本機服務，開啟 `/#amis-panel`，可逐一輸入 `plan.json` 的短句並按「翻譯並朗讀」。API 使用 `X-PaperVoice: local-ui` 與 JSON `source`、`dialect` 呼叫 `POST /api/amis-translate-speak`，WAV 以 base64 回傳。

單元／回歸測試：`.venv/Scripts/python.exe -m pytest -q`；`node --test tests/*.test.cjs`。新增測試涵蓋不需確認的 API、文件來源綁定、喉塞音保存、不支援字元拒絕、合成失敗保留譯文、一次觸發連續翻譯與合成，以及停止／新請求不播放舊結果。
