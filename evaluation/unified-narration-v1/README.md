# 統一語言選單與文件回答朗讀

日期：2026-10-02。

## 行為

主畫面移除台語／客語／阿美語實驗室，改為「提問與朗讀」單一選單。語言為華語、台語、客語、阿美語；客語再選四縣／海陸，阿美語再選譯文語別。

先由 `/api/ask` 取得中文文件回答與引用，再由 `/api/narrate` 翻譯並合成。中文回答、引用與草稿皆顯示；不需人工確認或复制譯文。切換語言後可以重讀同一份回答，文件摘要／原文也使用同一流程。語音提問收在可展開的選用區塊。

## 真實本機操作

從瀏覽器貼入自製「社區活動通知」，內容含「本活動免費，不必繳費。」「請攜帶身分證影本。」「如已完成補件，請忽略本通知。」點「幫我讀懂」後，以「需要繳費嗎？」提問。實際模型回答與引用均為「本活動免費，不必繳費。」。

| 所選語言 | 生成朗讀文字／譯文 | 音檔長度 | 瀏覽器結果 |
|---|---|---:|---|
| 華語 | 本活動免費，不必繳費。 | 3.434739 秒 | 提問後自動播放並自然結束 |
| 客語四縣 | 這隻活動免費，毋使繳費。 | 3.669478 秒 | 切換後重讀，自動播放並結束 |
| 阿美語秀姑巒譯文 | awaay ko payso, awaay ko ʼaca. | 3.008 秒 | 切換後重讀，自動播放並結束 |
| 台語 | 本活動免費，無需要繳費。 | 3.536 秒 | 切換後重讀，觀測播放中及自然結束 |

沒有用假回答或預錄音檔代替模型。本次測試是同一個費用回答的開發冒煙測試，不能當作一般翻譯正確率；海陸與其他阿美語譯文語別在本輪未做完整真人語音評測。文件欄位另有未通過檢查而隱藏的輸出，保留頁面提示，未將它當成完整文件辨識成功證據。

## 回歸與失敗處理

298 項 Python、47 項 JavaScript 測試通過。新增覆蓋語言／腔調路由、保留否定與例外的完整分句、過長文字不截斷、WAV 格式一致性、某句失敗時整段不播放、語言切換／停止／新請求不套用遲到結果。舊 API 繼續保留相容；主介面不載入舊實驗室控制腳本。

華語單次最多 1,800 字；其他語言最多 6 句、每句 80 字，只依完整句尾或換行分句，逗號與分號不拆開。客語超出限定句型會保留中文、提示切換華語；台語若翻譯完成但無完整白話字讀音，會保留譯文並說明無法朗讀；各句未全部完成時不回傳部分音檔。阿美語語別只影響譯文，仍共用一個 MMS 聲音。所有翻譯與發音尚未經母語者評分。

停止取消前端等待與播放；已送往本機模型的運算可能繼續至完成。新的合成在既有語音運算未結束時會提示忙碌，不會播放舊結果。
