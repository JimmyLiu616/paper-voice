# 台語翻譯候選：未採用

以 `plan.json` 的固定提示及六句原創公文短句測試 Gemma 3 4B；完整回覆及耗時見 `results.jsonl`。這是小型候選篩選，沒有母語使用者評分。

可直接觀察到的失敗包含：「身分證影本」被改為一般「證件的照片」；「只接受紙本，不接受線上」回覆成「毋擺紙本申請，毋擺線上申請」，未保留紙本可受理的規定。期限句亦產生不清楚的否定／時間用語，數字保留指令未完整遵守。

因此未提供此候選的自動文件翻譯端點。耗時 0.352–1.165 秒不能抵銷意思改變；此結論只適用本次模型、提示及六句測試，不能推論所有小模型皆無法翻譯。既有台語漢字轉白話字及 TTS 功能保持可用，但仍需要人工提供並核對台語。
