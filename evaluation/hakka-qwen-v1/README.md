# 本機客語翻譯替代候選：Qwen3 8B

> 2026-10-03 模型來源政策更新：本頁僅保留歷史證據，不授權重新執行。Qwen 及其衍生 OmniTranslate 禁用；mT5 候選發布者來源／授權未核准，亦不得啟用。見根目錄 MODEL_POLICY.md。
2026-10-02，使用者希望解除目前中文轉客語的限定句型限制。

## 資源查核

先前搜尋收錄的 `ngocthien/hakka-translation-model` 與 `ngocthien/hakka_translation_pinyin` 官方 Hugging Face API 均回 HTTP 401；匿名模型目錄以 `hakka-translation` 搜尋無結果。不能據此判定刪除、私有或其他存取原因，也不能把搜尋快取當作可下載證據。本轮公開 `hakka` 名稱查詢主要返回 ASR／TTS，沒有找到經確認可取得的專用中文→客語文字模型。這不是宣稱所有地方都沒有模型。

## 本機實驗

沿用已安裝的 `qwen3:8b`，不用新增模型下載。`plan.json` 在推論前保存 6 句與提示；提示含 5 組現有客語規則示例，未將它們當作母語者審定標註。第一句與提示示例重疊，只是管線檢查，不能當獨立評測。

`probe.json` 保留全部輸出，temperature=0、seed=42、關閉思考輸出，先保護數字標記、再驗證順序與單位並還原。

- 期限句、文件不齊全句及年齡費率句的輸出與中文原文完全相同（3/6）；相同漢字可能有跨語言共用用法，這項觀察本身不能作為母語判定，但沒有提供通用客語翻譯能力的充分證據。
- 「已完成報名的人不需要再次申請。」生成「係講已經完成報名嘅人毋需再次申請。」：額外加入條件用語，且用字與現有範例不同，未經母語者驗證。
- 首句 54.047 秒含模型冷載入，其餘 0.342–1.120 秒；僅為單次本機觀察。
- 沒有將這些候選譯文送入自動語音或部署成正式翻譯，也沒有計算 BLEU 或宣稱翻譯準確率。

結論：**未解除通用翻譯限制，候選不部署**。完成後釋放 Qwen3 GPU 並恢復 Gemma 文件模型。正式句型轉換與 VoxHakka 保持原狀。

## 可行的後續路徑

客委會[線上翻譯](https://speech.hakka.gov.tw/Translation/Online)提供華客雙向服務，公開說明非會員每日 1,000 字；網頁試用與程式 API 授權是不同事項。先前使用者表示尚無 API 資格、先完成本機版，因此沒有擅自把正式文件送至外部網站，也沒有拿網站試用介面充當免申請 API。

欲採線上通用翻譯，可依[官方 API 公告](https://www.hakka.gov.tw/chhakka/app/data/view?id=25&module=hotnews&serno=e049eaed-e159-4cb3-b0b4-72289ab37f18)確認目前申請方式、介面與資料使用條件。純本機通用化仍需可取得的專用權重，或有適當授權的平行語料及客語評估；不能只移除程式限制就視為完成。
