# 紙聲通：多語朗讀與辨識示範

新版影片約 77 秒，包含實際瀏覽器操作：原創通知圖片辨識（本次 8.4 秒）、台語漢字轉白話字並試聽「你好」、四縣客語「天公落水」。分段間停頓已剪除。

這是瀏覽器畫面取樣組成的示範影片，另配 Windows 華語旁白與本機生成的台語／客語音檔，**不是原生連續螢幕錄影或同步系統錄音**。影片標示此限制。首段尾端延長定格以保留完整旁白。畫面使用原創虛構通知；沒有個人文件。

華語文件尚不能自動翻成可靠台語／客語，發音仍待母語者核對。台語與客語模型為 CC BY-NC 4.0，示範限非商業用途。權重不包含在原始碼 ZIP 中，依 README 從各模型來源下載。

直接 Windows OCR：10 張配對圖片文字一致，OCR 階段中位數少 0.34 秒；不是通用準確率或整體推論保證。修復 OCR 後首次台語載入的 Windows DLL 衝突。Python 231 項測試通過。
