# mT5-small-hak 本機客語翻譯測試

測試日期：2026-10-02。**模型可在本機執行，能產生部分客語字詞，但日期、時間、年齡門檻與條件有明確遺失或變動；目前不接入紙聲通自動朗讀。**

## 模型與範圍

- 模型：[qavit/mt5-small-hak](https://huggingface.co/qavit/mt5-small-hak)，約 3 億參數，作者說明以臺灣客語辭典微調 mT5-small。
- 固定 revision：`231a3eefac886c436da8301e57f056cac7ff04ba`。
- 原始 FP32 Safetensors：1,200,729,512 bytes；SHA-256：`16669fa4d459a82a5e22b61dd71e00a7b88056e100e5bb00b56804a6bd2239d5`，下載後已驗證。
- 模型卡未提供授權、推論前綴、腔調及翻譯評測。公開可下載不等於已確認可再散布的開源授權；本報告不重新發布權重。
- 所有輸入均為本專案自建的診斷短句，推論完全在本機；沒有上傳使用者文件，也沒有新增訓練。

## 方法

10 個句子包括問候、免費、應備文件、截止時間、年齡及費用、已登記例外、紙本限制、委託書、假日順延與不退費。它們不是 80 個獨立案例，也不是正式翻譯評測集。

1. `probe.json`：10 句 × 6 種輸入格式，共 60 次 greedy 解碼。格式包括直接輸入、三種英文翻譯前綴與兩種中文前綴。這些是探索用法，並非作者公布的官方格式。
2. `beam4-probe.json`：同 10 句 × 直接輸入／英文 Chinese-to-Hakka 前綴，共 20 次 beam search（4 beams）補測。
3. 原始句子的 tokenizer token ID 與下載的原生 SentencePiece 模型逐一比對，10/10 相同。此檢查只排除這些輸入的分詞差異，不能證明所有版本完全等價。

環境：Windows、RTX 5060 Laptop GPU、Python 3.11、PyTorch 2.10.0+cu128、Transformers 5.18.0、SentencePiece 0.2.2、protobuf 7.36.2。FP32 推論，`do_sample=False`、`max_new_tokens=96`、seed 42。80 次生成均完成，沒有碰到生成長度上限。

greedy 單句計時中位數約 0.219 秒，beam4 約 0.313 秒，包含該句分詞、生成與解碼，不包含模型載入。這是單次開發環境觀察，並非穩定延遲保證。

## 代表性結果（逐字保留模型輸出）

| 原文 | 輸入與解碼 | 實際輸出 | 觀察 |
| --- | --- | --- | --- |
| 請在10月15日下午5點以前提出申請，逾期不受理。 | 直接輸入、greedy | 請在月月日逐日逐日提出申請,逾期毋受理。 | 日期和時間資訊損壞 |
| 同上 | 英文 Chinese-to-Hakka 前綴、beam4 | 請在十月15日前提出申請,逾期毋受理。 | 日期較完整，但仍漏掉下午 5 點 |
| 只有65歲以上才免費，其他人須繳500元。 | 直接輸入、greedy | 這下當多人當免費,其他人須繳500元。 | 65 歲門檻消失 |
| 同上 | 直接輸入、beam4 | 只有65歲下正免費,其他人須繳500元。 | 「以上」變成「下」，不能視為保留原條件 |
| 已經完成登記的人，不必再提出申請。 | 英文 Chinese-to-Hakka 前綴、beam4 | 佢已經完成登記个人,毋知再提出申請。 | 「不必」被改成「毋知」，未可靠保留免重複申請的意思 |
| 如果委託別人辦理，還需要附上委託書。 | 直接輸入、greedy |  阿公別人辦理,還需要附上委託書。 | 出現原文沒有的「阿公」，委託條件不完整 |
| 報名費300元，取消報名不退費。 | 直接輸入、greedy | 報名費300元,取消報名毋退費。 | 數字和主要字面資訊保留；自然度及腔調未經母語者評分 |

全部 8 種已測設定（6 種 greedy + 2 種 beam4）都沒有完整保留截止案例的日期與下午 5 點。部分輸出有「毋、个、係」等字詞，但不能因此認定整句翻譯正確。中文前綴還會被一起翻譯或照抄到答案。

沒有將未變動的中文文件名稱一律判為錯誤，也沒有將數字仍存在一律判為正確；例如年齡門檻的方向可在數字保留時改變。本次沒有 BLEU/COMET 分數、參考客語譯文或母語者評測，不宣稱整體準確率，更不宣稱所有可能輸入格式都已測完。

## 結論

這是先前資源搜尋漏掉的可下載專用候選，提供了另一條研究路徑；但在本專案重要資訊上已有直接反例。更換已測提示格式與 beam search 仍不足以解決問題。保留模型供研究，紙聲通維持既有受限句型客語流程，沒有將本次輸出送入 TTS 或部署新翻譯模型。

若繼續改進，仍需確認作者實際訓練格式與授權，並以有授權的平行語料改善、另設測試集驗證。不能把此次找到模型說成已完成通用中文轉客語。

## 重跑

下載上述固定 revision 的模型與分詞器至本機資料夾，於有相同依賴的環境執行：

```powershell
python scripts/probe_hakka_mt5.py --model-dir .runtime/mt5-small-hak
python scripts/probe_hakka_mt5.py --model-dir .runtime/mt5-small-hak --num-beams 4 --basic-prefixes --output-name beam4-probe.json
```

腳本強制使用離線模式，權重須預先備妥。原始紀錄見 `download.json`、`probe.json`、`beam4-probe.json`。初次啟動曾補裝缺少的分詞依賴，並修正 Windows 中文路徑的 SentencePiece 載入方式；這些環境問題不算翻譯失敗。Transformers 5.18 載入時警告 shared/lm_head 權重不同而不予綁定；原始模型設定為 `tie_word_embeddings=false`，測試未修改或合併這兩份權重。
